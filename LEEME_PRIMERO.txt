PEDIDOS LIBERADOS SCS - V2 PORTABLE (SIN SDK .NET)
==================================================

OBJETIVO
--------
Esta versión evita por completo la necesidad de compilar PedidosLiberados.Service.exe.
Funciona con Windows PowerShell 5.1 y el Programador de tareas de Windows, ambos incluidos
en Windows corporativo. La tarea se ejecuta cada 5 minutos con una cuenta corporativa.

No necesita:
- .NET 8 SDK
- Visual Studio
- dotnet publish
- instalar módulos PowerShell
- Excel/Office para leer Proveedores.xlsx

REGLAS
------
- Impresión 1: se valida y, si todo es correcto, se envía.
- Impresión 2 o superior: se mueve a "reimpresiones" y NO se envía.
- El proveedor se busca siempre en Proveedores.xlsx de la carpeta raíz.
- EMAIL_1 = Para.
- EMAIL_2, EMAIL_3... = CC.
- Tras envío correcto: pedidos enviados\AAAA\MM.
- Si Exchange acepta el correo y falla el movimiento: ENVIADO_PENDIENTE_ARCHIVO.
  No se reenvía; sólo se intenta archivar.
- Si una ejecución termina mientras estaba ENVIANDO: REVISION_MANUAL.
  No se reenvía automáticamente.
- Proveedor no encontrado o sin email: ESPERA_DATOS; vuelve a comprobarse cada ciclo.
- Errores de correo: 3 intentos (inmediato, +5 min, +15 min) y después incidencia permanente.
- Se calcula SHA-256 como salvaguarda adicional frente a duplicados.

El Excel de incidencias se regenera en cada ciclo. Si un usuario lo tiene abierto,
el programa lo volverá a intentar en la siguiente ejecución.

INSTALACIÓN
-----------
1. Copie/descomprima esta carpeta en una ubicación estable del equipo.
2. Botón derecho en INSTALAR_TAREA.cmd -> Ejecutar como administrador.
3. Indique la cuenta de servicio corporativa.
4. Windows pedirá la contraseña de esa cuenta para registrar la tarea.
   La contraseña NO se guarda en estos scripts.
5. La tarea "SCS - Pedidos Liberados" se ejecutará cada 5 minutos.

PRIMERA PRUEBA SEGURA
---------------------
Mail.Enabled viene en FALSE.

1. Deje Mail.Enabled=false.
2. Ejecute EJECUTAR_AHORA.cmd.
3. Compruebe que:
   - lee Proveedores.xlsx;
   - reconoce los nombres;
   - las reimpresiones se clasifican;
   - genera reportes/panel;
   - no se envía ningún correo.
4. Configure Exchange en config.json.
5. Haga una prueba controlada con un proveedor/correo interno.
6. Sólo entonces cambie:
   "Enabled": true

EXCHANGE
--------
Debe completar en config.json:
- SmtpHost
- SmtpPort
- EnableSsl
- AuthenticationMode

Para autenticación integrada:
"AuthenticationMode": "WindowsIntegrated"

La tarea usará las credenciales de la cuenta de servicio que la ejecuta.

IMPORTANTE SOBRE THUNDERBIRD
----------------------------
La tarea no abre Thunderbird. Por tanto, la firma automática configurada en Thunderbird
no se inserta. Si se desea la misma firma, copie su HTML en firma.html.

CONFIRMACIONES
--------------
Se solicitan confirmación de lectura y notificaciones de entrega/fallo mediante cabeceras
SMTP cuando el servidor Exchange y el cliente receptor las admitan. No todos los servidores
externos respetan estas solicitudes.

PANEL
-----
Ejecute PANEL_CONTROL.cmd después de al menos un ciclo.
Para forzar un ciclo sin esperar 5 minutos, use EJECUTAR_AHORA.cmd.

--------------------
